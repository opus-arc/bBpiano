# Security Policy

## Supported Versions

bBpiano is currently in an active research and development stage.

At the moment, only the latest version on the main branch is considered supported.

| Version | Supported |
| ------- | ---------- |
| main    | ✅ |
| older experimental versions | ❌ |

---

## Reporting a Vulnerability

Although bBpiano is currently a local audio application and research-oriented project, security-related reports are still appreciated.

If you discover a security issue, memory corruption problem, unsafe realtime behavior, or any vulnerability related to the audio engine or application runtime, please report it privately via:

arcopus07@gmail.com

Please avoid publicly disclosing vulnerabilities before they have been reviewed.

As this project is maintained independently and still evolving rapidly, response times may vary. Nevertheless, all legitimate reports will be taken seriously and investigated carefully.
